# Bugs

## 大参考图上游请求超时
- 状态：防御性加固完成；历史根因仍未复现。
- 现象：历史上曾有 1.37MB PNG 参考图导致 302 生图请求挂满约 280 秒。
- 复现条件：当前正交实验无法稳定复现；体积、格式、像素均不是确定性单因子。
- 当前推断：上游瞬时拥塞或特定文件编码属性；本轮目标是结构性限制上游参考图输入，而非宣称定位根因。
- 防御：前端正常上传路径严格 `≤800KiB`；服务端生成上游前统一收口到 `≤800KiB` 且长边 `≤1920px`，透明 PNG 保留；归一化失败按需求原图回退。
- 实测：服务端回归 4/4；`3,680,324B / 3000x3000` 真实 Gemini 参考图在上行前变为 `421,759B / 1920x1920`，27 秒生成成功。
- 验证缺口：前端浏览器 Canvas 路径未做运行时大图实测；上游长期稳定性不能由单次成功推断。
